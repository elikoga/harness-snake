snakecore · wasm parameter search

Pick a seed and press Play.

One C engine (csrc/core.c) plays an expectimax parameter search (node budget, deterministic food RNG). The same core is compiled to WASM (build/snakecore.wasm — its result is logged to the console) and this page animates js/mirror.mjs's playGameTrace, which is bit-for-bit identical to that core across every backend.
